# sala de aula

### Este projeto é um recurso educacional para o aprendizado de programação de sistemas no curso instrumental do Senac Rio Grande do Sul, através da elaboração de um software

O projeto é um sistema de gestão de sala de aula, em que será possível:

- Adicionar usuários
- Remover usuários
- Atribuir nota aos alunos
- Atualizar status do usuário
- Imprimir relatório de usuários, com notas
